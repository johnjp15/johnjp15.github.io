# johnjp15.github.io

This is the public GitHub Pages site (branch `master`). Each web app is a folder here, e.g. `times-tables/`.

The source, tests and docs for those apps live in the private `johnjp15/web-apps` repo, in the folder with the same name. Make changes there, deploy with that app's `tools/deploy.sh`, then push both repos. A new web app starts as a new folder in `web-apps`, not as a new repo.
